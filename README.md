# Data & Algorithms in Teaching — Interactive OER

A self-contained, browser-based sensibilization module for teacher educators. It uses three illustrative primary-school scenarios (assessment, differentiation, and learning analytics) to prompt decisions and critical reflection about data and algorithmic systems in teaching.

## Run locally

Open `index.html` in a modern web browser. No build tools, dependencies, server, or API keys are required.

## Publish with GitHub Pages

1. Create a public GitHub repository named `data-algorithmic-literacy`.
2. Upload `index.html`, `README.md`, and `LICENSE` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the deployment. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/data-algorithmic-literacy/`.

## Adaptation

Edit the scenario content and feedback in the `scenarios` array near the bottom of `index.html`. The page is intentionally self-contained and can be adapted without a development environment.

## Notes

The scenarios are illustrative, not descriptions of specific commercial platforms or validated assessment instruments. Reflections are processed locally in the browser; this page does not transmit responses to a server.
